# Тетрадь

Нативное приложение для iPad. Открой `Tetrad.xcodeproj`, выбери схему **Tetrad** и запусти её на iPad. Минимальная версия системы — iPadOS 17.

## Где искать нужный код

| Задача | Файл или папка |
| --- | --- |
| Запуск приложения и переход с полки в тетрадь | `App/TetradApp.swift` → `App/TetradRootView.swift` |
| Полка, предпросмотр подписей на обложках, создание и удаление тетрадей | `Features/Shelf` |
| Экран открытой тетради, подпись обложки, листание и меню | `Features/Editor/NotebookEditor.swift` |
| Миниатюры, перестановка, вставка и удаление листов | `Features/Editor/NotebookContents.swift` |
| Панель и настройки инструментов | `Features/Editor/EditorTools.swift` и `ToolSettings.swift` |
| Ввод стилусом и жесты | `Features/Editor/PageCanvas.swift` |
| Отмена и повтор действий | `Features/Editor/PageEdits.swift` |
| Размер листа, настройки бумаги и данные штрихов | `Models` |
| Отрисовка бумаги, штрихов и импортированных страниц | `Rendering/PageRenderer.swift` |
| Сохранение тетрадей, последнего открытого листа, штрихов и вложений | `Storage` |
| Импорт файлов, экспорт PDF, резервные копии и восстановление | `Files` |

## Как менять приложение

Начинай с экрана, на котором пользователь выполняет действие. Например, для изменения жеста листания открой `PageCanvas.swift`. Для изменения самого перехода между листами открой `NotebookEditor.swift`. Если нужно изменить разметку бумаги, начни с `PageRenderer.swift`. Его используют редактор, миниатюры и экспорт PDF, поэтому все три получат одинаковое оформление.

Новый Swift-файл добавляй через Xcode в папку по назначению и отмечай **Target Membership → Tetrad**. Модели описывают данные, экраны управляют действиями пользователя, а чтение и запись проходят через `Storage`.

## Совместимость с существующими тетрадями

У листа есть постоянный идентификатор. Номер в оглавлении — его текущая позиция. При перестановке меняется порядок идентификаторов, а штрихи и вложения остаются привязанными к своему листу.

При изменении моделей `Codable` проверяй, что приложение открывает прежние тетради и резервные копии. Хранилище поддерживает листы со старыми числовыми идентификаторами и записи первого прототипа. Резервные копии используют формат версии 1, включая ранние копии без вложений.
